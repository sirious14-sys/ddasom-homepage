# 이 폴더 이름이 `_초안_functions` 인 이유 (2026-10-08)

`배포.py`는 원본 폴더에서 wrangler를 실행하므로, 루트에 `functions/` 폴더가 있으면 정적 파일 목록(올릴것)과 상관없이 Functions 코드가 함께 배포될 수 있습니다.
견적 서버 접수는 **사장님이 켜기로 결정하기 전까지 배포되면 안 되므로** 이름을 바꿔 두었습니다.

켜는 순서:
1. 사장님 결정(결재함): 알림 방식·수신처·확인 담당·개인정보 문구
2. 이 폴더 이름을 `functions` 로 되돌리고, `tests/quote.test.mjs` 의 경로도 `../functions/api/quote.js` 로 되돌린 뒤 `node --test tests/*.mjs`
3. README_견적접수.md 의 KV·환경변수 절차 → apply.html 의 `data-server-submit="off"` 를 `on` 으로
